# مصادر البيانات والحدود

- **الصلاة:** [AlAdhan Calendar API](https://aladhan.com/prayer-times-api)، بإحداثيات المدينة وطريقة الحساب والمنطقة الزمنية المحددة في الملف. تُحفظ نسخة صالحة محليًا بعد فحص اكتمال الشهر وترتيب الصلوات. تقويم المسجد المحلي قد يختلف. المناطق القطبية والحالات التي لا تعيد ترتيبًا يوميًا صالحًا قد تحتاج محولًا آخر؛ لا نصنع أوقاتًا بديلة.
- **الهلال:** [صفحة مباريات النادي الرسمية](https://alhilal.com/ar/matches/mens-team/fixtures). استخراج بيانات الصفحة قابل للتأثر بتغييرات الموقع؛ لا يعتمد على جدول ثابت مكتوب في التطبيق.
- **بقية الأندية:** واجهات ESPN العامة مثل [فرق الدوري السعودي](https://site.api.espn.com/apis/site/v2/sports/soccer/ksa.1/teams?limit=100). هذه نقاط نهاية عامة مستخدمة عمليًا، وليست تعهدًا بعقد API ثابت. جدول `/schedule?fixture=true` للمواعيد المستقبلية، مع اختيار الدوريات صراحة. آخر تحقق من أمثلة الأندية: 2026-10-22. لا ضمان لتوفر كل بطولة أو تعريب أسماء كل الخصوم.
- **الشعارات:** من مضيفي المصدر HTTPS المعتمدين، مع اسم النادي بديلًا عند غياب الصورة. تبقى الشعارات ملكًا لأصحابها؛ لا توجد علاقة رسمية بالأندية أو خدمات البث.
- **الطقس:** [Open-Meteo](https://open-meteo.com/en/docs)، حسب الإحداثيات. يفحص التطبيق بنية الاستجابة قبل استبدال المخزون الصالح؛ قد تنتهي صلاحية البيانات أثناء انقطاع طويل.
- **الخصوصية:** لا توجد خدمة حسابات أو خادم خاص بالمشروع. يتصل التلفزيون بمصادر الطقس والصلاة والمباريات والشعارات مباشرة؛ مزودوها يستقبلون عنوان الشبكة، وخدمات المدينة تستقبل الإحداثيات المطلوبة. بيانات إعداد الجهاز وADB تبقى محليًا ولا ينبغي نشرها.
- **الخط:** [ثمانية](https://font.thmanyah.com/) اختيار محلي، غير موزع هنا. لا تمنح رخصة MIT الخاصة بالكود ترخيصًا للخطوط أو الشعارات.

صور `screenshots/` حقيقية للنسخة المخصصة بتبوك والهلال قبل تعميم ملف الإعداد، مع خط أضيف محليًا. ملف `site/preview/dashboard.json` عينة تصميم ثابتة؛ لا يمثل مصدر المباريات الحي أو مواعيد يعتمد عليها المستخدم. يظهر وضع المعاينة في الصفحة عند تشغيلها في متصفح عادي.
