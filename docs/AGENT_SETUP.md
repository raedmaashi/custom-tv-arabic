# دليل الإعداد للأيجنت المحلي

## 1. اجمع الاختيارات

اسأل مرة واحدة قدر الإمكان:

- ما المدينة والدولة؟ وما طريقة حساب الصلاة المفضلة إن كانت معروفة؟
- ما فريق كرة القدم المفضل؟ والدوريات أو البطولات المطلوبة؟
- ما التطبيقات المراد وضعها في الرئيسية وبأي ترتيب؟
- أي اللوحات تريد إظهارها: الصلاة، المباريات، الطقس؟
- هل ترغب في تنظيف اختياري للتطبيقات المقترحة؟ وهل تريد منع السكون أثناء توصيل الكهرباء؟
- ما طراز التلفزيون، وعنوان التصحيح المعروض في إعداداته؟

لا تستخدم تبوك والهلال إلا كاختيار صريح أو مثال معاينة. عند غياب الفريق يمكن إخفاء لوحة المباريات؛ لا تختلق فريقًا للمستخدم. يمكن تخطي التنظيف والطاقة إذا لم يطلبهما.

## 2. جهز ملف المستخدم

انسخ `profiles/example.json` إلى `profiles/my.local.json`. تحقق من إحداثيات المدينة ومنطقتها الزمنية IANA، واختر طريقة AlAdhan المناسبة بموافقة المستخدم عند اختلاف الطرق. القيم المحسوبة لا تضمن مطابقة تقويم مسجد بعينه؛ اعرض الطريقة والمدينة بوضوح.

للهلال، استخدم `provider: alhilal` مع الاسم `الهلال`: هذا محول موقع النادي الرسمي. للفرق الأخرى استخدم `provider: espn` ورقم الفريق الصحيح و`leagues` التي تحققت من تغطيتها. `profiles/clubs.json` نقطة بداية للأندية السعودية، وليس دليلًا على تغطية كل البطولات.

مثال لاكتشاف فرق دوري من المصدر:

```text
https://site.api.espn.com/apis/site/v2/sports/soccer/ksa.1/teams?limit=100
https://site.api.espn.com/apis/site/v2/sports/soccer/ksa.1/teams/817/schedule?fixture=true
```

**وجود `fixture=true` مهم**؛ الطلب الافتراضي قد يعيد نتائج ماضية. تحقق من هوية الفريق وحالة `pre` والتواريخ قبل البناء. أضف كل بطولة متاحة برمزها الصحيح؛ الدوري المحلي وحده لا يشمل الكؤوس أو البطولات القارية تلقائيًا. الشعارات تُقرأ من المصدر وليست بيانات يكتبها الأيجنت من ذاكرته.

`apps` قائمة حزم التطبيقات المثبتة وأسمائها بالترتيب المطلوب. اكتشف الحزم من التلفزيون بدل تخمين أسماء APK. اللوحات تحفظ اختياراتها على التلفزيون؛ إعداد `panels` يمثل الافتراضي عند أول تشغيل فقط. التحديث لا يمحو اختيارات المستخدم.

```sh
python3 scripts/configure.py --profile profiles/my.local.json
python3 -m unittest discover -s scripts -p 'test_*.py'
node --test web-tests/*.test.cjs
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

استخدم JDK 17 وAndroid SDK/Build Tools 34 وPython 3.10+؛ `ANDROID_HOME` مسار SDK. يتطلب Windows أحيانًا `python -m pip install tzdata`، ويستخدم `gradlew.bat`.

## 3. اتصل بالجهاز الصحيح

اطلب من المستخدم تفعيل خيارات المطور والتصحيح وقبول رسالة الكمبيوتر على التلفزيون. في Wireless debugging، استخدم عنوان الاقتران ورمزه ثم عنوان **الاتصال** المعروض. لا تطلب رمزًا غير ظاهر أو تفترض منفذًا ثابتًا. إذا كان التصحيح مغلقًا، يحتاج ذلك تدخلًا من المستخدم على الجهاز؛ لا يمكن للأيجنت فتح خدمة مغلقة عن بعد.

```sh
adb connect TV_IP:PORT
python3 scripts/tv.py --device TV_IP:PORT inspect
```

يطبع الفحص الطراز والشركة والرقم التسلسلي وAndroid وواجهة Home الحالية. طابقها مع جهاز المستخدم. تحفظ نتائج الفحص في `.local/` المستبعد من Git. لا تطبع معرّفات الجهاز في منشور عام.

## 4. ثبت وافحص قبل تغيير الرئيسية

```sh
python3 scripts/tv.py --device TV_IP:PORT --serial HARDWARE_SERIAL install --apk app/build/outputs/apk/debug/app-debug.apk
```

هذا يفتح التطبيق ويحفظ Home السابقة دون استبدالها. افحص على التلفزيون:

1. اتجاه العربية وتوازن أيقونات التطبيقات وشعارات الأندية، وحركة التركيز بالريموت.
2. تشغيل تطبيق فعلي وعودة زر Home، والعمل بدون لوحة مفاتيح أو فأرة.
3. صحة المدينة والتوقيت وطريقة حساب الصلاة، وموعد مباراة مستقبلية مقابل المصدر.
4. إخفاء كل لوحة وإظهارها، ثم إعادة فتح التطبيق للتأكد من بقاء الاختيار.
5. الإعدادات والساعة المحيطية اليدوية والرجوع منها.
6. عند انقطاع الشبكة: يعرض المتاح من المخزون مع حالة التحديث؛ لا تختلق بيانات جديدة.

المعاينة في المتصفح تعرض بيانات عينة للتصميم، وليست اختبارًا لبيانات المدينة أو الفريق. التحقق من التكامل يحتاج التطبيق المثبت ومصادره الحية. بعض بطاقات التلفزيون وHDMI تعتمد على تطبيقات الشركة المصنعة.

بعد نجاح الفحص:

```sh
python3 scripts/tv.py --device TV_IP:PORT --serial HARDWARE_SERIAL make-home
```

ابقِ واجهة الشركة الأصلية مثبتة ومفعلة. إن رفض الجهاز تعيين Home، أبلغ المستخدم بالقيد ولا تعطل الواجهة الأصلية لإجباره.

## 5. الخيارات الإضافية والاستعادة

اتبع [دليل التنظيف](CLEANUP.md) لعرض القائمة ومراجعتها ثم تنفيذ النطاق الذي اختاره المستخدم. منع السكون منفصل:

```sh
python3 scripts/tv.py --device TV_IP:PORT --serial HARDWARE_SERIAL keep-awake
python3 scripts/tv.py --device TV_IP:PORT --serial HARDWARE_SERIAL keep-awake --apply
```

مؤقت الإغلاق، والإغلاق التلقائي من الشركة، وHDMI CEC قد تتغلب على إعدادات Android؛ افحصها من إعدادات التلفزيون عند استمرار الإطفاء. لا تعد المستخدم بمنع كل أنواع الإغلاق.

للاستعادة استخدم نفس ملف الحالة والرقم التسلسلي:

```sh
python3 scripts/tv.py --device TV_IP:PORT --serial HARDWARE_SERIAL restore
```

أعط المستخدم مسار `.local/tv-state.json` ونسخة احتياطية منه خارج المستودع إن أراد. الاستعادة تعيد Home والحزم والطاقة المسجلة فقط؛ لا تحذف التطبيق. لا تستبدل ملف الحالة بملف جهاز آخر. التطبيق له معرّف مستقل `tv.customhome.launcher` ويستطيع التعايش مع واجهات سابقة.

## 6. التسليم

اذكر بدقة ما بُني وما ثبت وما اختُبر فعليًا، وتغطية المباريات، ومسار APK والحالة، وأي قيد لم يُحل. لا ترفع ملف المستخدم أو النسخ الاحتياطية أو الخطوط أو مفاتيح التوقيع إلى GitHub.
