# التحقق قبل النشر — 2026-10-22

- نجح بناء Debug وRelease، واختبار كل منهما، وفحص Android Lint لكليهما من بناء نظيف باستخدام JDK 17 وSDK 34.
- **24 اختبار Java** لكل نمط بناء: تقويم الصلاة، اختلاف المنطقة الزمنية، نهاية اليوم والشهر، تحليل صفحة الهلال، أمان روابط الشعارات، ومواعيد ESPN المستقبلية واستبعاد النتائج الماضية والمباريات الملغاة.
- **21 اختبار JavaScript**: التطبيقات والترجمة والخلفيات، ومنع رد طقس ناقص أو غير صالح من استبدال المخزون السليم.
- **9 اختبارات Python**: ملف التخصيص والتحقق من الفريق والمنطقة الزمنية، رفض جهاز أو نسخة احتياطية برقم مختلف، حماية الحزم، وتسجيل الحالة الأصلية قبل التعطيل، وحفظ Home عند تغيير Android لاختيارها أثناء التثبيت، ومسار أمر التثبيت. تستخدم أجهزة محاكاة للأوامر ولا تعطل تطبيقات فعلية.
- نجح توليد ملف آخر للندن/ليفربول وبناء اختبارات Android به، ثم أعيد المثال العام إلى تبوك/الهلال.
- تحقق حي بالمحلل نفسه من موقع الهلال، ومن جدول النصر لدى ESPN باستخدام `fixture=true`: استُخرجت مباريات مستقبلية، مع شعارات من مضيف المصدر. التغطية تتغير ولا تشمل تلقائيًا كل بطولة.
- ثبت APK العام على IMPEX evoQ 4K / Android 11 كتطبيق مستقل إلى جانب الواجهة الخاصة. ظهرت مواقيت اليوم والطقس والمباريات والشعارات، وفتحت إعدادات اللوحات وتأكد حفظ إخفائها بعد إعادة فتح التطبيق. تأكد كذلك حفظ Home السابقة أثناء التثبيت؛ فقد يمحو Android الاختيار المفضل عند ظهور واجهة جديدة. بيانات تعريف الجهاز ولقطات الاختبار التفصيلية بقيت محليًا.
- معاينة التنظيف على التلفزيون تعرفت على الحزمتين المرفقتين دون تطبيق تعطيل إضافي. عملية التعطيل الأصلية واختبار الاستعادة ليستا ادعاء اختبار على كل طراز.
- فحص ملفات النشر استبعد عناوين الجهاز وأرقامه ونسخ حالته ومفاتيح التوقيع وملفات الخط الخام وAPK الخاص. الصور المنشورة للنسخة الشخصية بخط أضيف محليًا، كما هو موضح في README.

لا تعني هذه الاختبارات اعتماد كل أجهزة Android TV أو ضمان استمرار خدمات البيانات الخارجية. نتائج GitHub Actions متاحة من تبويب Actions؛ يلزم التحقق البصري والريموت على جهاز القارئ قبل تعيين الواجهة الرئيسية أو التنظيف.
